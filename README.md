# MUSIC\_Tuner

Developed with Unreal Engine 5



テーマ：和音で敵を「**共鳴**」させて倒すアクションゲーム



操作方法：

・移動　WASD

・カメラの視点操作　マウス移動

・攻撃　マウス左クリック

・回避（ドッジロール）　移動キー×2



ゴール：**ラスボスを倒すこと**



攻撃方法について：

敵本体を攻撃することでダメージを入れることができるが、わずかなダメージしか与えられない。

より強い攻撃にするためには、敵から発生する波動の弾を攻撃することが必要である。

弾を攻撃すると音が鳴るので、その音がなっている間に次の弾に攻撃を与えることで

コンボ攻撃ができる。

「初撃」→「2コンボ」→「3コンボ」と攻撃をすることで、3コンボ目で最大のダメージを与えられる。



攻撃の際に発生する音は敵から発生する音と親和性の高い和音になっており、この3音を重ねることで

共鳴し、より強い攻撃になる。
